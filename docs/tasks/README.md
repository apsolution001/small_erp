# Task board

Each task is one file, `T-NNN-slug.md`, with frontmatter `status: todo | in-progress | done | blocked`. Execute a task with the `implement-task` skill or the `senior-coder` agent.
Detailed task files for sprints 2–6 are generated by each sprint's spec task (T-200, T-300, ...), once the spec is written.
